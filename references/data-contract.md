# 数据契约与判定规则

## 1. 运行时绑定

以下名称是业务能力标签，不是 MCP 工具全名。先确认同一 MCP 服务组中的工具描述、输入 schema 和输出语义；不同实现可以使用不同的请求包装、分页和字段投影参数。

| 业务能力 | 必要语义 | 仅允许用途 |
| --- | --- | --- |
| `product_node` | 站点、关键词或节点路径；返回节点路径、名称、商品数和实际提供的叶子信息 | 候选类目发现与叶子验证／待确认节点定位 |
| `market_research` | 站点、月份、精确节点路径；返回类目月度指标 | 完整类目月度 `totalUnits` |
| `competitor_lookup` | 站点、月份、精确节点路径筛选；返回商品标题 | 仅用于类目语义补充核验 |

若一个服务组不能确认全部必要语义，不得绑定该组。多组均可绑定时，必须由用户选择当前任务的服务组。

## 2. 字段判定

- 将 `totalUnits` 视为销量主指标，必须是有限、非负数。数值 0 有效。
- 将 `null`、缺失、空串、布尔值、非数值文本、负数、目标路径重复或工具错误视为不可确认，不得转成 0。
- `avgUnits`、`avgRevenue`、`avgPrice`、`totalProducts` 是可选展示字段；缺失时显示“—”，不估算。
- 仅接受与最终 `nodeIdPath` 完全匹配的单一记录。父节点、子节点、相邻节点、关键词结果或商品级结果都不可替代。
- 所有金额仅按数据源返回的市场币种展示，不进行汇率换算。

## 3. 类目粒度确认

优先使用 MCP 明确返回的 `isLeaf`：`true` 为“已验证叶子类目”，`false` 为非叶子。

`isLeaf` 缺失时，只有绑定工具的公开说明明确支持“按节点路径获取直接下级节点”时，才能按该说明验证。不得因路径最末级、商品数、任意节点查询返回空数组或类目名称而自行推断其为叶子。

若 MCP 不能验证叶子，但已返回一个语义高度相关、路径完整且 `nodeIdPath` 明确的候选，进入“用户确认”流程：

1. 展示英文／本地类目路径和 `nodeIdPath`，并明确说明 MCP 未提供叶子验证。
2. 仅在用户肯定确认该路径后，将 `category.confirmationStatus` 写为 `user_confirmed_unverified`；看板显示“用户确认的最细匹配类目（SellerSprite MCP 未提供叶子验证）”。
3. 用户确认前不得调用销量采集，也不得生成 HTML。用户未确认、拒绝或候选不唯一时继续澄清。

自动验证成功时，写入 `category.confirmationStatus=verified_leaf`。两个状态均可进入销量采集；它们的展示口径不得混淆。

## 4. 24 个月观察窗口

1. 目标截止月为执行时区的上一个自然月。
2. 从目标截止月向前生成 24 个按月连续的日历月份。
3. 数据表始终保留全部 24 个目标月；缺失月份标识为 `missing` 或 `collection_interrupted`。
4. `availableMonths` 只统计 `totalUnits` 已确认的月份。`expectedMonths` 固定为 24。

状态：

- `ready`：24/24 月有效。
- `partial`：1–23 月有效；可展示已确认数据与覆盖数，不得伪造完整趋势或跨期增长。
- `blocked`：在商品名称和有效站点已齐全后，0 月有效，或连接、类目确认无法完成，或用户未确认 MCP 无法验证叶子的候选。输入尚未齐全时只继续收集输入，不生成阻断页面。

## 5. 比较与洞察

- 仅当两个 12 月周期均为 12/12 月有效时，计算总销量变化量和增长率。
- 部分覆盖时，周期卡应标明实际覆盖数，例如“近 11 个月销量（11/12 月）”；变化量和增长率显示“—”。
- 仅当最近六个日历月均有效时，比较最近 3 月与其前 3 月。
- 峰值只在已确认月份中寻找，并写明“已确认月份内”。
- 洞察只陈述数据现象，不推断季节性、促销、竞品或运营原因。

## 6. 调用控制

- 对相同连接、站点、月份、类目路径和字段集合使用任务内缓存。
- 不并发执行同一连接的月度请求。
- 仅在工具或响应明确给出限流、等待或重试条件时遵循其要求。
- 遇到限流、超时或服务中断而未能完成采集时，保留已确认月并将未采集月标识为 `collection_interrupted`；不得当作源数据为 0 或缺失。
- 参数、权限、字段或结构错误不得反复重试。
